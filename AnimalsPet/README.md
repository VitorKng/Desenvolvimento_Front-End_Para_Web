# 🐾 AnimalsPet

Projeto acadêmico feito em sala de um site fictício com tema de pet shop, feito com HTML e CSS puros. A AnimalsPet é apresentada como um ecossistema dedicado ao cuidado, à saúde e à felicidade de cães, gatos e outros pets.

🔗 **Acesse o site:** https://VitorKng.github.io/AnimalsPet

## 📋 Seções do site

- **Hero**: imagem de destaque em tela cheia.
- **Sobre**: apresentação da AnimalsPet e dos seus serviços.
- **Galeria de fotos**: seis imagens de animais, com efeito de zoom ao passar o mouse.
- **Mapa**: localização incorporada pelo Google Maps.
- **Contato**: formulário com nome, e-mail e mensagem.

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox, `object-fit`, transições)
- Google Maps Embed
- GitHub Pages (hospedagem)

## 🚀 Como executar localmente

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/VitorKng/AnimalsPet.git
   ```
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo `index.html` para abrir no navegador.

Não é preciso instalar nada.

## 🌐 Publicação

O site é publicado pelo GitHub Pages, a partir da branch `main` (pasta raiz). Para publicar uma versão própria:

1. Faça um fork ou envie os arquivos para um repositório seu.
2. Vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/ (root)**, depois clique em **Save**.
