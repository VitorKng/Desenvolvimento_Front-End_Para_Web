# ⚽ Brasileirão 2026

Site estático sobre o Campeonato Brasileiro de 2026, com informações sobre a competição, galeria de fotos, tabela de classificação e histórico de campeões.

🔗 **Site no ar:** `https://VitorKng.github.io/Brasileirao2026`

> Troque o link acima pelo endereço real depois de ativar o GitHub Pages.

---

## 📋 Seções do site

| Seção | Descrição |
|-------|-----------|
| **Sobre** | Apresentação do Brasileirão 2026 |
| **Galeria** | Fotos e imagens do campeonato |
| **Tabela** | Classificação dos 20 clubes (Pos, Clube, P, J, V, E, D, GP, GC, SG, %) |
| **Histórico** | Campeões do Brasileirão de 2016 a 2025 |
| **Contato** | Formulário de contato (apenas visual) |

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox, transições e layout responsivo básico)

Sem frameworks, sem dependências e sem etapa de build.

## 🚀 Como rodar localmente

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/VitorKng/Brasileirao2026.git
   ```
2. Abra a pasta do projeto.
3. Dê dois cliques no `index.html` para abrir no navegador.

## 🌐 Como publicar no GitHub Pages

1. No repositório, vá em **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Selecione a branch **main**, a pasta **/ (root)** e clique em **Save**.
4. Aguarde de 1 a 3 minutos. O link público aparecerá no topo da página de configurações.

> ⚠️ O arquivo principal precisa se chamar exatamente `index.html` e ficar na raiz do repositório. Use nomes de arquivo em minúsculas, sem espaços e sem acentos, pois o GitHub Pages diferencia maiúsculas de minúsculas.

## ℹ️ Observações

- Os dados da tabela de classificação e do histórico foram inseridos manualmente no HTML e não se atualizam sozinhos.
- O formulário de contato é apenas visual: o GitHub Pages hospeda somente páginas estáticas e o formulário não envia mensagens.
