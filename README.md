---

## 📋 Sobre o Projeto

Aplicação web estática desenvolvida para aplicar conceitos fundamentais de criação de interfaces, organização de layouts e boas práticas de desenvolvimento front-end.

### ✨ Tecnologias e Recursos
- **HTML5:** Estruturação semântica do conteúdo
- **CSS3:** Estilização, posicionamento e identidade visual
- **JavaScript:** Dinamismo e interatividade da interface
- **Visual Studio Code:** Ambiente de desenvolvimento integrado
- **GitHub Pages:** Hospedagem e deploy contínuo da aplicação
